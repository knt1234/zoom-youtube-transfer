# 経理

お金関係（請求書・支払い等）のファイルはこのディレクトリに置く。

## 請求書フォーマット化

請求書がアップロードされたら、以下のフォーマットに整形する。
整形の仕組み本体は Skill として実装されている: `~/.claude/skills/invoice-format/`

### 出力フォーマット

```
【請求書情報】

支払いの目的：

払い出し口座：（振込元の会社名など）

期日　　　　：（支払期日）

金額　　　　：（税込金額、¥表記）

振込先　　　：（銀行名 支店名）

口座番号　　：（預金種別 口座番号）

名義人名　　：（振込先口座の名義人）
```

### ルール

- 「支払いの目的」は請求書からは読み取れない情報なので、**常に空欄のまま**にする（ユーザーが手動で記入する）。
- 他の項目は請求書の記載内容からそのまま抽出する。読み取れない項目があれば、憶測で埋めず空欄にして、その旨をユーザーに伝える。

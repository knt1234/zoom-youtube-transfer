# 経理

お金関係（請求書・支払い等）のファイルはこのディレクトリに置く。

## 請求書フォーマット化

請求書がアップロードされたら、以下のフォーマットに整形する。
整形の仕組み本体は Skill として実装されている: `~/.claude/skills/invoice-format/`

### 出力フォーマット

```
【請求書情報】

支払いの目的：

払い出し口座：（創智／未来推進／CBS出版／メタライズ のいずれか）

期日　　　　：（支払期日）

金額　　　　：（税込金額、¥表記）

振込先　　　：（銀行名 支店名）

口座番号　　：（預金種別 口座番号）

名義人名　　：（振込先口座の名義人）

備考　　　　：（請求書に振込関連の特記事項があれば記載。無ければ空欄）
```

### ルール

- 「払い出し口座」は自社4社(創智／未来推進／CBS出版／メタライズ)のいずれか。請求書の宛名(「〇〇御中」)に書かれている自社側の会社名から判定する。一致しない場合はユーザーに確認する。
- 「支払いの目的」は請求書からは読み取れない情報なので、整形結果では空欄のまま出力しつつ、**必ずユーザーに目的を尋ねる**。回答があれば反映して再提示する。
- 他の項目は請求書の記載内容からそのまま抽出する。読み取れない項目があれば、憶測で埋めず空欄にして、その旨をユーザーに伝える。
- 請求書に振込名義の指定・手数料負担者などの特記事項がある場合は、「備考」欄にそのまま（請求書固有の値があればその値に置き換えて）記載する。
- 振込名義の指定がある場合は、ルールの説明で終わらせず、担当者がそのままコピペで使える実際の文字列（例:「振込名義：カ)メタライズ006973-001」）を備考欄に書く。契約者名が不明な場合はユーザーに確認する。
- あわせて、なぜその名義にする必要があるのか（理由）も一言添える。理由は請求書に書かれている指定文そのものを根拠として示すだけでよい（例:「請求書に『お振込名義はご契約者様のお名前＋加盟店コードで』と指定されているため」）。請求書に書かれていない業務上の理由を勝手に推測して付け加えない。
